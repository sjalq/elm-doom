Doom in Elm

id Software's 1993 Doom (DOS v1.9), frame for frame, as a pure Elm program: sjalq/elm-doom (source). It needs a WAD, the file with the game's levels, pictures and sounds. Pick one:

Or give your own: an address of a WAD (or of a zip with one in it), or a file from your computer. A patch is a PWAD played with the IWAD, as Doom's -file.

A file from another site loads only if that site lets other sites fetch it (CORS). A file from your computer stays on it. You can drop one on this page too.
